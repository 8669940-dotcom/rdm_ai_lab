## 3. 결측·극단값 처리와 이유

- 학습 고장 코드·유형 각 1,707건, 시험 각 876건, 이번 달 각 62건의 공란은 모두 예방정비 기록에 위치한다. 해당 없음 범주로 구분하되 생성 규칙을 확인한 사실로 단정하지 않는다.
- 학습 경과일 공란 150건은 모두 관측 첫 정비다. 관측 이전 이력이 없는 상태를 표시하고 학습 구간 중앙값으로 대체했다. 0일로 단정하지 않았다.
- 학습 운용중단 시간 999시간·정비 비용 19,000만원이 관측됐다. 원본 행을 유지하고 학습 99백분위 상한 처리와 미처리를 앞 검증에서 비교했다.
- 최종 구성의 상한 처리 사용 여부: True. 운영 모델의 학습 상한은 아래와 같다. 다른 분할의 상한도 해당 학습 구간에서만 학습했다.

| 컬럼 | 운영 학습 상한 | 학습 처리 셀 | 시험 처리 셀 | 이번 달 처리 셀 |
| --- | --- | --- | --- | --- |
| downtime_hours | 40.275 | 24 | 21 | 2 |
| maintenance_cost | 386.000 | 23 | 8 | 1 |

운영 상한 기준 셀 수는 운영 모델을 설명하는 집계다. 시험 제출 모델은 시험 시작 전 학습 구간에서 자체 상한을 학습하므로 위 시험 열의 수가 제출 모델의 실제 처리 수를 뜻하지 않는다.
수치 IQR은 검토 후보 탐색에만 사용했으며 등급·이진값은 IQR 후보로 표시하지 않았다. 원본 삭제 행은 0건이다.

## 4. 피처·컬럼 선택

현재 정비 직후 확정되는 정비 정보와 현재일 이전 동일 드론 이력만 사용했다. 과거 90일 정비·사후/긴급정비 수, 관측 고장 이후 경과일, 이전 예방정비 후 누적 비행시간 증가, 이전 180일 정비 실패 수를 만들었다. 이력 없는 상태는 별도 표시한다. 2025·2026년 이력은 앞 파일과 연결하고 정답을 쓰지 않는다.

기본 제외: 드론 ID는 이력·제출 식별자, 원 정비일은 정렬·월 주기 피처, 정답은 평가 대상, 월 가동률은 예측 직후 가용성 미확인 및 이번 달 열 부재다.
부대·고장 코드 포함 구성도 앞 검증에서 비교했다. 최종 포함 여부는 `selected_spec.context`와 비교표에 기록했다. 확률 가중치를 사람이 임의 지정하지 않았고, 모델이 학습한 규칙을 사용했다. 중요도는 별도 측정값이다.

사용 피처: 경과연수, 고장 심각도, 운용중단 시간, 수리 시간, 교체 부품 수, 정비 비용, 정비 성공 여부, 누적 비행시간, 직전 정비 경과일, 직전 정비 이력 공란, 정비 월 주기(sin), 정비 월 주기(cos), 이전 관측 정비 수, 이전 90일 정비 수, 이전 90일 사후·긴급정비 수, 이전 관측 고장 경과일, 이전 관측 고장 존재, 이전 예방정비 후 비행시간 증가, 이전 예방정비 관측, 이전 180일 정비 실패 수, 드론 유형, 정비 구분, 고장 유형

## 7. 선택과 독립된 하반기 평가

정비 기록 643건·재고장 176건 (27.37%). AP 0.7877, 사다리꼴 PR-AUC 0.7870, ROC-AUC 0.8814, Brier 0.1118.

AP는 확률 순위를 따라 재현율이 늘어날 때의 정밀도를 요약하며 정밀도·재현율의 균형을 본다. ROC-AUC는 양성과 음성의 순위 구분력이다. 정원 제한이 있는 업무에서는 월별20대 적중과 함께 해석한다. AP와 PR 곡선의 사다리꼴 면적은 계산법이 달라 이름을 구분한다. 정확도만으로 선정 품질을 판단하지 않았다.

## 8. 위험 표시 기준과 비용

| 미탐지 비용(만원) | 앞 검증 선택 기준 | 위험 표시 건 | FN | 앞 검증 비용(만원) | 뒤 검증 비용(만원) |
| --- | --- | --- | --- | --- | --- |
| 300 | 0.40140788 | 111 | 40 | 18660 | 26100 |
| 600 | 0.22762210 | 182 | 27 | 27120 | 32100 |

검증 정비 건별 비용은 `FN×미탐지비용+flagged×60`(만원), 판정은 `prob >= threshold`다. 가능한 판정 변경점, 모두 표시/표시 안 함을 비교해 최소 비용을 골랐다. 동률은 표시 수가 적고 임계값이 큰 정책 순이다. 앞 검증 선택 기준을 뒤 검증에 고정 적용했으며 시험 데이터로 기준을 고르지 않았다.
정원 20대는 별도다. 운영 비용은 같은 최신 드론 후보에서 `미선정 재고장×300+선정대수×60`으로 별도 저장했다. 정원 제한 없는 표시 비용과 숫자를 직접 합산하지 않는다. 점검으로 선정 재고장을 예방한다는 단순 가정이며 실제 예방률·예산 절감의 증거가 아니다.

## 9. 2026년 1월 선정과 설명

106건에서 최신 81대를 만들고 확률 순 20대를 선정했다. 위험 표시 기준은 0.40140788, 기준 이상 22대 중 2대가 정원 밖이다. 초과 위험 드론은 확률 순 대기 명단으로 관리하고 운용 전 상태 확인·추가 점검 가능성을 정비반장이 판단한다.
개별 요인은 한 특성을 운영 학습 중앙값/최빈값으로 바꾼 예측 확률과의 차이다. 합산 기여도나 SHAP가 아니며, 상관·중복 특성으로 민감도가 가려지거나 중복될 수 있다. 인과 설명으로 해석하지 않는다. 검증 전체 중요도는 하반기 특성 셔플 5회에 따른 AP 감소로 별도 계산했다.

20대 명단과 권고: `reinspection_plan_2026-01.md`, 원 확률 CSV와 세부 요인은 `analysis_results.json: current.equipment`.

## 10. 산출물·검증·재현

```powershell
python scripts/profile_data.py
python scripts/train.py
python scripts/build_report.py
python scripts/check.py --predictions reports/test_predictions_2025.csv
python -m streamlit run app.py
```

- 시험 예측: `test_predictions_2025.csv`, 3열·1,241행·원본 키 전량·유한 확률 검사.
- 앱과 보고서 공통 근거: `analysis_results.json`; 예측 모델과 카드: `../artifacts/`.
- 실행 환경: python=3.12.10, pandas=3.1.1, numpy=2.5.5, scikit_learn=1.9.1, streamlit=1.67.0. 의존성은 `../requirements.txt`에 고정했다.
- 데이터·코드 해시: `analysis_results.json: data_sha256, code_sha256`; 주요 산출물 해시: `output_manifest.json`.
- 실제 검증 결과: `check_result.json`, 앱 동작 테스트와 실행 서버 점검 기록. 준비 검사만으로 모델 성능을 보증하지 않는다.

## 11. 한계와 다음 검토

가상 데이터의 관측 결과이며 실제 기종·부대의 안전성을 보증하지 않는다. 반복 관측한 드론의 미래를 평가한 것으로 처음 보는 드론·부대에 대한 이전 성능은 검증하지 않았다. 하반기 6개월의 변동과 시험 채점 단위도 확인해야 한다. 재학습한 모델의 확률 척도가 변할 수 있어 고정 임계값은 추가 보정·전향 검증이 필요하다. 실제 점검 개입 효과는 관측하지 않았다. 월말 최신 기록 계획을 월중 실시간 선제 배치 결과로 해석하지 않는다. 최종 판단은 정비 담당자가 한다.
